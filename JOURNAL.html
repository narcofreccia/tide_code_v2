Locked decisions

  • T3-Code architecture: TypeScript tide-server owns everything; thin clients over typed WS RPC; event-sourced (command → decider → events → projector). No Effect.
  • Tauri desktop shell supervising a bun-compiled server sidecar (not Electron). Web app must run in a plain browser.
  • Harnesses v1: Claude Code (Agent SDK), Codex (app-server), OpenCode (serve + SDK), Pi (RPC + trimmed extensions). Bring-your-own-subscription.
  • Harness-native planning / sub-agents / permissions, surfaced by Tide. ProposedPlan → "Implement in new thread" (never auto-executes).
  • UI is thread-first (docs/design/ui.md): Mission Control landing → Rail · Thread (primary) · Workbench (Changes / files / terminal bound to the worktree) · focus modes ⌘1/2/3.
  • Out of scope: Tutor, voice, router/classifier, custom planner, custom safety engine.
  • Way of working: orchestrator session writes contracts + validates; Opus subagents implement on disjoint dirs. Files ≤ 600–800 LOC.
